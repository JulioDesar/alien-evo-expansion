Alien Evo Expansion
===================

A Minecraft Forge 1.20.1 expansion for Alien Evolution, Omnitrix Evolution,
and Into The Omniverse. Planned systems include the Nemetrix, Antitrix, and
Albedo's Stabilizer.

Development
-----------

Run `gradlew.bat runClient` to start the development client.
Run `gradlew.bat build` to create the mod jar.

All contributions must follow `AGENTS.md`. It defines the English-only code and
naming convention, localization rules, package layout, Forge practices, and the
required validation workflow.

DNA Instability Prototype
-------------------------

Enable the invisible DNA instability state for a player:
`/superpower add alienevoexpansion:dna_instability <player>`

Disable it and return the player to human form:
`/superpower remove alienevoexpansion:dna_instability <player>`
